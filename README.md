# OOP_lab4

Лабораторная работа № 4, вариант 19, мир E «Банк». Программа хранит вклады, кредиты и карты в одной коллекции, вычисляет суммарный годовой эффект и ищет продукт с максимальной метрикой.

## Контракт классов

| Класс | Поля | `metric()` | Особый метод |
| --- | --- | --- | --- |
| `BankProduct` | — | Чисто виртуальный метод | `explicit operator double()` возвращает метрику, `operator==` сравнивает её с абсолютной точностью `1e-6` |
| `Deposit` | Сумма, ставка, срок в годах, капитализация | Без капитализации `sum * rate`, с капитализацией `sum * ((1 + rate)^years - 1) / years` | `isCumulative()` |
| `Credit` | Сумма, ставка, срок в годах, аннуитет | Без аннуитета `sum * rate`. С аннуитетом 12 месячных платежей по формуле варианта | `isAnnuity()` |
| `Card` | Расходы за год, ставка кешбэка | `spending * rate` | `hasCashback()` проверяет, положительна ли ставка |
| `ProductCollection` | Динамический массив указателей, размер, ёмкость | `TotalMetric()` суммирует метрики | `MaxMetricProduct()` ищет максимум за один проход |

В формуле аннуитета месячная ставка `r = rate / 1200`, число платежей `n = 12 * years`, месячный платёж `A = sum * r / (1 - (1 + r)^(-n))`. При нулевой ставке годовой платёж равен `sum / years`. Для аннуитета ставка задаётся годовым процентом (например, `12` для 12%), в остальных формулах ставка вводится долей (например, `0.12` для 12%). Так используются формулы из условия.

Суммы, расходы и ставки конечны и неотрицательны, срок в целых годах положителен, метрика должна быть конечной. По умолчанию числовые поля равны нулю, срок равен одному году, флаги выключены. Конструктор с некорректными параметрами бросает `std::invalid_argument`. При ошибочном чтении поток получает `failbit`, прежние поля объекта сохраняются.

## Полиморфизм и владение

- `BankProduct` абстрактный. Каждый наследник реализует `metric`, `Print`, `Read` и `Clone` с `override`. Свободные `operator<<` и `operator>>` вызывают виртуальные `Print` и `Read`. `metric`, `Print`, `Clone`, сравнение и приведение к числу объявлены `const`, поскольку только читают объект. `Read` изменяет его после проверки параметров. В меню специальные методы вызываются после успешного `dynamic_cast`.
- Коллекция хранит собственный динамический массив `std::unique_ptr<BankProduct>`. `Add` сохраняет копию фактического типа через `Clone`. Защищённые операции копирования и перемещения базового класса доступны наследникам. Код, работающий с базовым классом, получает ссылку или указатель.
- Правило пяти реализовано в коллекции. Копирование клонирует каждый продукт, перемещение передаёт массив и оставляет исходную коллекцию пустой. Удаление элемента и уничтожение коллекции освобождают принадлежащие им объекты. Виртуальный деструктор базы гарантирует вызов деструктора наследника.
- `At` и `Remove` принимают индекс с нуля и бросают `std::out_of_range` при неверном индексе. Меню показывает номера с единицы. `MaxMetricProduct()` возвращает указатель на объект коллекции или `nullptr`, если она пуста. При одинаковых метриках выбирается первый продукт. Указатель действителен, пока объект принадлежит коллекции.

## Ввод и вывод

В меню поля вводятся через пробелы в одной строке.

| Продукт | Порядок полей | Пример |
| --- | --- | --- |
| Вклад | `sum rate years cumulative` | `1000 0.125 2 1` |
| Кредит | `sum rate years annuity` | `2000 12 3 1` |
| Карта | `spending rate` | `10000 0.015625` |

Флаги принимают `0` и `1`. Потоковый вывод вклада выглядит как `Deposit: sum=1000 rate=0.125 years=2 cumulative=1`. Ту же запись можно прочитать через `operator>>` в объект соответствующего типа. Меню выводит годовой эффект и результат специального метода отдельными строками.

## Структура и сборка

- `include/lab04/` и `src/` содержат интерфейсы и реализацию. Консольное меню находится в `src/main.cpp`.
- `test/` содержит тесты Google Test для продуктов и коллекции.

На macOS с установленным GNU GCC 16:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug -DCMAKE_CXX_COMPILER=g++-16
cmake --build build -j 4
ctest --test-dir build --output-on-failure
./build/lab04_main
```

В CLion открой папку `OOP_lab4` и укажи GNU GCC в Toolchains. На этом Mac путь к C++ Compiler — `/opt/homebrew/bin/g++-16`. Цель `lab04_main` запускает меню, `tests` запускает тесты. CMake использует установленный Google Test или скачивает версию 1.15.2 при первой настройке. AddressSanitizer включён для всех целей и конфигураций.
